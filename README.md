# ONSET Studio · Bilingual Demo

[Open the live demo](https://q11z.github.io/onset-studio-demo/)

A browser demo of the ONSET fitness studio mini program, with English as the default language and a Simplified Chinese option. Your language selection is remembered in your browser.

## Try the workflow

1. Book a class in the student view.
2. Open the coach dashboard from **My classes**, confirm the booking, and request settlement.
3. Return to the student view to confirm attendance and deduct a session.

The demo also includes nutrition logging, weight history, member management, and messages. Choose a language from the menu above the app. All records are simulated and saved in your browser. Use **Reset demo** to start again.

## 中文说明

这是 ONSET 健身工作室小程序的网页版交互演示，支持简体中文与 English 切换。

可以体验学员预约、教练确认、下课结算、课时扣减、营养打卡、体重记录、学员管理和消息通知。所有操作使用当前浏览器中的模拟数据，点击「重置演示」可以恢复初始状态。

## Run locally

Open `index.html` in a browser. The site uses static HTML, CSS, JavaScript, and image files, with no build or backend configuration required.

## Deployment

GitHub Pages publishes the root of the `main` branch. The application runs locally in each visitor's browser.
